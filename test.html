美國

  1. 紐約

    2. 時代廣場

    又稱為時報廣場，因《紐約時報》早期在此設立的總部大樓，如今這個有著百年歷史的廣場，是遊客到紐約的必到景點之一，也是各個大片的取景地。

    ➢ 官方網站 : 點此

    ➢ 交通

    ►地鐵

    -可乘坐地鐵黃線N、Q、R線至49街(49 St)下車即可。
    -可乘坐地鐵S線、1、2、3、7號線至時代廣場42街(Times Sq - 42 St)下車，步行3分鐘即可。

    ►公車 : 可乘坐公車M104至7Av/w47St站下車即可。

    自由女神像

    是美國國家的紀念碑，是法國在1876年贈送給美國的獨立100週年禮物。女神矗立在紐約市哈德遜河口的自由島上，被譽為美國的象徵。
    1984年，它被列入世界遺產名錄。

    ➢ 官方網站 : 點此

    ➢ 門票

    普通票 成人18美元 ; 62以上老人14美元
    4-12歲兒童9美元 ; 4歲以下兒童免費
    套票 成人21美元 ; 62以上老人17美元
    4-12歲兒童12美元
    *普通票包括抵達自由島和埃利斯島、女神像墊座和語音導覽器
    *套票除包括普通票內容外，還包括了抵達女神冠冕處門票。

    ➢ 開放時間

    08:30 – 16:00

    ➢ 交通

    從炮台公園坐渡輪前往自由島，可乘坐地鐵、公車、計程車到達。

    中央公園

    內部可分為南北中三塊，以公園內最大的湖Reservoir為界。園內設有淺綠色草地、樹木鬱鬱的小森林庭院、溜冰場、回轉木馬、
    露天劇場、兩座小動物園，可以泛舟水面的湖、網球場、運動場、美術館等等，是一塊完全人造的自然景觀。

    ➢ 官方網站 : 點此

    內設部分景點收費

  2. 阿拉斯加

    3. 極光列車

    路途會經過「迪納利國家公園和保留區」只有在週末的時候有行駛，可以做為觀光列車，行駛速度不快，沿途列車長會介紹景點，
    遇到美景時，列車會放慢速度，讓乘客盡情的觀賞與拍照，這些只有搭乘「冬季極光列車」才能看到的風景。

    ➢ 票價

    成人 : $216美金 ; 小孩(2-11歲) : $108美金 ; 年長者(65歲以上) : $108美金

加拿大

  1. 阿爾伯塔省

    2. 冰原公路

    被視為北美最美麗的公路之一，從班夫國家公園至賈思珀國家公園，綿延229公里，沿途可看到瀑布、翡翠湖、
    草原和白雪覆頂的山峰的景致變化，美麗如一幅畫卷。

  2. 安大略省

    3. 尼亞加拉大瀑布

    是世界第一大跨國瀑布，也是世界七大奇景之一，它那豐沛而浩瀚的水量和磅礡的氣勢，無論在瀑布的湖盆底部或其背後深處，
    還是佇立在巨大的約13層落差的馬蹄形峭壁邊緣噴霧之中，都讓人感受到心靈在震顫。

    ➢ 官網 : 點此

    ➢ 門票

    無需門票

    ➢ 開放時間

    全天開放，其中參加各項活動的開放時間請參見官網：http://www.niagaraparks.com/hours/niagaras-fury.html

    ➢ 交通

    搭乘火車到Niagara Falls Funiculars Upper Station下車
